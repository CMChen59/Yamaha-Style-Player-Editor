(2) How to use Playlist on PSR-SX920
    1. Unzip the downloaded file using your preferred computer program.
    2. Copy the "PlaylistForPSR-SX920" folder to the root folder of your USB flash drive.
    3. Connect the USB flash drive to a [USB TO DEVICE] terminal of PSR-SX920.
    4. Press the [PLAYLIST] button to call up the Playlist display. 
    5. Touch the Playlist file name shown at the top of the display to call up the Playlist file selection display. 
    6. Select the desired Playlist file, 
       User tab > USB1 > PlaylistForPSR-SX920 > desired Genre folder > desired Playlist file
       and then close the display.
    7. Touch a Record name on the Playlist display, and then touch [Load]. PSR-SX920 is ready to play. 


(3) Notice
    -Make sure you copy "PlaylistForPSR-SX920" folder to the root folder of the USB flash drive.
    -Make sure no other USB flash drive is connected to PSR-SX920.
    -If you change the name of files/folders, Playlist will not work.
