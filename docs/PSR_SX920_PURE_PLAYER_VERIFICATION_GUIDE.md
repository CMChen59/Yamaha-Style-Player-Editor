## 📂 情境一：USB 隨身碟載入實體伴奏演奏驗收（離線伴奏驗證）

此測試旨在確認匯出的 `.sty` 檔案在琴端作業系統下完全合規、可正常載入、且自動伴奏轉調功能完美無損。

```text
[電腦端匯出 _edited.sty] ──> [存入 USB 隨身碟] ──> [插入 PSR-SX920] ──> [開 ACMP 左手彈和弦演奏]
```

### 1. 操作步驟
1. **存入隨身碟**：將電腦瀏覽器下載的檔案（例如 `LoveSong.T547_edited.sty`）複製到 USB 隨身碟根目錄或常用伴奏資料夾。
2. **插琴載入**：
   * 將隨身碟插入 PSR-SX920 面板右上角或背面的 **[USB TO DEVICE]** 插孔。
   * 點選琴端觸控螢幕左上角的 **[STYLE]** 伴奏區塊（或實體面板按鍵），上方分頁切換至 **[USB]**。
   * 找到並點選該伴奏檔案載入。
3. **伴奏播放與左手和弦轉調測試**：
   * 開啟面板上的 **[ACMP]**（自動伴奏開關）與 **[SYNC START]**（同步啟動）。
   * 在鍵盤左手伴奏區（通常為 F#2 以下）彈下 **C 大三和弦**，伴奏即刻啟動。
   * 依序彈奏：`C` ➔ `Am` ➔ `F` ➔ `G`。

### 2. 驗收核對清單 (Checklist)
* [ ] **檔案相容性**：檔案載入順暢，琴端無跳出「Data Error」或「Unrecognized Format」。
* [ ] **CASM 轉調驗證**：左手變換和弦時，Bass 音、鋼琴/吉他和弦聲部能正確跟隨轉調，沒有怪異跳音或走音。
* [ ] **編輯音符發聲**：剛才在電腦上修改的聲部（如 Rhythm 鼓點或 Bass 樂句），在 SX920 原廠雙向低音反射立體聲喇叭中能如期精準發聲。
* [ ] **段落切換**：按下琴端面板的 **[MAIN A]**、**[MAIN B]**、**[AUTO FILL]**、**[ENDING]** 能正常切換。
* [ ] **OTS 右手音色切換**：按下琴端面板右側的 **[OTS 1]**、**[OTS 2]**、**[OTS 3]**、**[OTS 4]**，右手音色正常切換。

## 🎹 情境二：Web MIDI 直連即時監聽與編輯驗收（工作站連線驗證）

此測試旨在體驗將 PSR-SX920 作為「硬體旗艦音源機」，在電腦網頁上邊播邊改、琴端即時發聲的無縫互動！

```text
┌──────────────────────┐   USB-B 線 (to Host)   ┌──────────────────────┐
│  電腦網頁 (Chrome)   │ ═════════════════════> │  Yamaha PSR-SX920    │
│  player.html 編輯器  │   Web MIDI 8 軌即時排程 │  旗艦 AWM2 原生音色發聲 │
└──────────────────────┘                        └──────────────────────┘
```

### 1. 硬體連接與琴端設定
1. **連接線材**：使用一條標準 USB 傳輸線（USB Type-B 轉 Type-A/Type-C），將電腦連接至琴背面的 **[USB TO HOST]** 連接埠。
2. **琴端 MIDI 模板設定**（關鍵步驟）：
   * 在 PSR-SX920 螢幕右側按下 **[MENU]** 實體按鍵。
   * 點選螢幕上的 **[MIDI]** 圖示。
   * 在左側的預設範本清單中選擇 **「Song」**（最推薦，8~15 通道直通發聲）或 **「All Parts」**。
   * 確認琴上的主音量旋鈕與 **[STYLE-ACMP]** 音量滑桿適度推開。

### 2. 網頁操作步驟
1. 開啟電腦瀏覽器：[http://localhost:5173/player.html](http://localhost:5173/player.html)。
2. 在「聲音發聲來源選擇」區域，點選 **「Yamaha 實體電子琴 (PSR-SX920 Web MIDI)」**。
3. 檢查「MIDI 輸出埠」下拉選單是否已出現 `Digital Workstation` 或 `PSR-SX920`：
   * 點擊 **`[🎵 琴端發聲測試]`** 按鈕，聽琴端是否發出清脆測試風鈴聲確認連線。
4. 點選 **`[▶ 播放全曲 (All)]`** 或 **`[🎧 僅播此軌 (Solo)]`**：
   * 此時所有伴奏聲部的聲音皆由 PSR-SX920 實體硬體發出！
5. 在下方單軌編輯器中進行即時操作：
   * 點選琴鍵列：聽琴端發出該樂器音色。
   * 拖拉音符或修改力度數值：音符即時在琴端以新音高與力度發聲。

### 3. 驗收核對清單 (Checklist)
* [ ] **硬體音源發聲**：Web MIDI 模式下，聲音 100% 來自 PSR-SX920 喇叭，音質為旗艦 AWM2 原廠立體聲。
* [ ] **零延遲同步**：網頁上的小節游標與琴端發聲完美同步，無任何拖泥帶水的掉拍感。
* [ ] **即時試聽連動**：在單軌編輯器點擊音符或調整力度時，琴端能立即給予發聲反饋。

## 🛠️ 常見問題排查 (Troubleshooting)

| 問題現象 | 可能原因 | 解決方式 |
| :--- | :--- | :--- |
| **琴端載入伴奏顯示無聲** | 琴端伴奏音量滑桿未推開或 ACMP 未啟動 | 檢查琴端面板左側 **[ACMP]** 燈號是否恆亮，並將伴奏推桿推至 100 左右。 |
| **左手彈奏沒有自動轉調** | 伴奏檔 CASM 區塊毀損或缺失 | 透過我們本次更新的 `replaceSectionChannelNotes` 匯出，CASM 區塊已通過 100% 反向防呆驗證，可確保轉調無損。 |
| **電腦連線時琴端沒發出聲音** | 琴端 MIDI 模板未設定為「Song」 | 進入琴端 MENU ➔ MIDI ➔ 選擇「Song」模板，將 1~16 通道全部解鎖為直通音源。 |
| **網頁提示未偵測到 MIDI 設備** | USB 線材接觸不良或瀏覽器未授權 | 請在 Chrome 網址列左側點擊鎖頭圖示，將「MIDI 設備」權限設為「允許」，並點擊網頁上的 `[🔄 重新整理設備]`。 |
