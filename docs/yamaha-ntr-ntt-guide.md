# Yamaha SFF / CASM — NTR 與 NTT 伴奏轉調規則完全參考指南

> **本指南作為 Yamaha 伴奏（`.STY`）二進位 CASM 結構中「音符轉調規則（NTR）」與「音階對照表（NTT）」的標準工程與樂理規範。**  
> 供後續系統實裝【任務 2-4E】單軌固定音高直通鎖定、段落切片裝配或手工微調伴奏時查閱與遵照執行。

---

## 一、 Yamaha 伴奏轉調底層核心架構（二階段串聯管線）

Yamaha 伴奏鍵盤（PSR-SX920 / SX900 / Genos）在琴端偵測到演奏者左手按下和弦時，對 STY 伴奏檔中的 MIDI 音符執行的是**兩階段串聯即時運算**：

```mermaid
flowchart LR
    A["MIDI 原始音符"] --> B["【第一階段：NTR】<br/>根音大位移 (電梯)"]
    B --> C["【第二階段：NTT】<br/>和弦音階吸附 (磁鐵)"]
    C --> D["琴端實體發聲音高"]
```

- **第一階段：NTR（Note Transposition Rule，音符移調規則）——「電梯」**
  - 決定這組音符是否要隨左手的**根音（Root）** 進行「整組等距上下搬移」。
- **第二階段：NTT（Note Transposition Table，音階對照表）——「磁鐵」**
  - 決定這組音符在移調後，是否要拿當前的**和弦性質（Chord Type，如大三、小三、七和弦）** 去進行「音階吸附與和聲修正」。

**鐵律：只要其中一個開關沒關掉，琴端就會在某個層面上更動您的音符！**

## 二、 NTR 參數詳解（根音移調）

在 CASM 二進位標籤（`Ctb1` / `Ctb2`）中，NTR 佔 1 位元組：

| NTR 參數值 | 代碼 | 核心機制 | 適用場景 |
| :--- | :--- | :--- | :--- |
| **`Root Transpose`** | `0x00` | **根音移調（開電梯）**：音符隨著左手按下的根音等距平移（例如左手按 D，音符集體升 2 半音；按 F，集體升 5 半音）。 | 一般伴奏軌（Bass、Chord 1/2、Pad、一般過門插音）。 |
| **`Root Fixed`** | `0x01` | **根音固定（關電梯）**：**絕對不隨左手根音升降**，音高死死釘在錄製時的原始高度。 | 打擊鼓組（Rhythm 1/2）、固定對位插音、防呆 Intro Solo。 |

## 三、 NTT 參數詳解（和弦音階吸附）

NTT 決定琴端如何微調音階中的各個音程度數：

| NTT 參數值 | 代碼 | 核心機制 | 適用場景 |
| :--- | :--- | :--- | :--- |
| **`Bypass`** | `0x00` | **直通模式（拔磁鐵）**：**完全不進行和弦吸附或音階變形**，100% 忠實輸出原始音程。 | 打擊樂、固定旋律 Solo、演歌導音原汁原味樂句。 |
| **`Melody`** | `0x01` | **旋律模式**：**保護旋律音程走勢與經過音**，隨和弦溫和轉換調性音階，不破壞歌唱性。 | 伴奏副旋律（Phrase 1/2）、木吉他挑音、鋼琴跑音。 |
| **`Chord`** | `0x02` | **和弦吸附模式**：**強力吸附至和弦內音**（1、3、5、7 度），非內音會被拉近折疊。 | 伴奏柱狀和弦（Chord 1/2）、三和弦鋪底（Pad）。 |
| **`Bass`** | `0x03` / `0x81` | **低音模式**：專門確保 Bass 音符咬合和弦根音與五度骨幹音，並支援轉位和弦（Slash Chord）。 | 貝斯聲部（Bass，Ch 10）。 |
| **`Harmonic Minor`** | `0x07` | **和聲小調模式**：保留小調第 7 度導音（如 Am 之 G#），防止被削平。 | 小調樂曲伴奏、演歌風格伴奏。 |

## 四、 NTR / NTT 四大經典組合全景矩陣

| NTR（電梯） | NTT（磁鐵） | 琴端實際聽感與表現 | 經典應用場景 |
| :--- | :--- | :--- | :--- |
| **`Root Fixed`<br/>(關閉電梯)** | **`Bypass`<br/>(拔掉磁鐵)** | **【音高絕對鎖定】**<br/>不管左手每兩拍如何頻繁換和弦（C ➔ Am ➔ F ➔ G），右手音符（如 `C-D-E-F-G-A-B-C`）**死死釘在原音高，零位移、零變形！** | 1. 穿透全曲的固定對位插音<br/>2. 左手解鎖防呆 Intro/Ending Solo |
| **`Root Transpose`<br/>(開啟電梯)** | **`Bypass`<br/>(拔掉磁鐵)** | **【整組坐電梯飄移】**<br/>音程完好無損，但旋律會隨左手按鍵上下暴移。左手若換和弦，旋律整段翻車。 | 原廠 Intro / Ending 單鍵直通前奏（演奏時左手不能亂按和弦） |
| **`Root Fixed`<br/>(關閉電梯)** | **`Chord` / `Melody`<br/>(開啟磁鐵)** | **【原地結巴變形】**<br/>音高雖沒大位移，但音符被和弦強力磁吸，經過音被打結削平（如 C-D-E 變成 C-C-E）。 | 打擊樂組（Drums/SFX） |
| **`Root Transpose`<br/>(開啟電梯)** | **`Chord`<br/>(開啟磁鐵)** | **【標準伴奏模式】**<br/>隨根音移調，且緊密吸附至左手彈奏的三和弦/七和弦。 | 吉他刷弦、鋼琴和弦（Chord 1/2）、弦樂長音（Pad） |
| **`Root Transpose`<br/>(開啟電梯)** | **`Melody`<br/>(開啟磁鐵)** | **【隨和弦轉調之旋律】**<br/>隨根音移調，且保留完整旋律音程與花音（隨和弦換音階）。 | 循環伴奏中的過門插音（Phrase 1/2） |

## 五、 Yamaha 8 大伴奏聲部（Ch 9~16）推薦配置速查表

| MIDI 通道 | SFF 伴奏聲部名稱 | 預設建議 NTR | 預設建議 NTT | 設計原因與聽感效益 |
| :---: | :--- | :--- | :--- | :--- |
| **Ch 8 (9)** | **Rhythm 1** (打擊樂) | `Root Fixed` | `Bypass` | 鼓點音高固定，換和弦絕對不可變更音高。 |
| **Ch 9 (10)** | **Rhythm 2** (鼓組) | `Root Fixed` | `Bypass` | 標準爵士鼓組，絕對不可隨和弦移調。 |
| **Ch 10 (11)** | **Bass** (貝斯) | `Root Transpose` | `Bass (0x81)` | 隨和弦根音走動，小調走小調根音，支援轉位和弦。 |
| **Ch 11 (12)** | **Chord 1** (伴奏和弦1) | `Root Transpose` | `Chord (0x02)` | 鋼琴或節奏吉他，緊密咬合左手和弦內音。 |
| **Ch 12 (13)** | **Chord 2** (伴奏和弦2) | `Root Transpose` | `Chord (0x02)` | 輔助和弦織體，和聲飽滿不撞音。 |
| **Ch 13 (14)** | **Pad** (鋪底弦樂) | `Root Transpose` | `Chord (0x02)` | 多音和弦長音，必須吸附三和弦，避免走味。 |
| **Ch 14 (15)** | **Phrase 1** (插音1) | `Root Transpose` 或 `Root Fixed` | `Melody` 或 `Bypass` | **依需求分流**：<br/>• 隨和弦轉調插音：`Transpose + Melody`<br/>• 貫穿固定旋律：`Fixed + Bypass` |
| **Ch 15 (16)** | **Phrase 2** (插音2) | `Root Transpose` 或 `Root Fixed` | `Melody` 或 `Bypass` | 同 Phrase 1，支援雙樂器對位（如二胡 + 吉他）。 |

## 六、 兩大高階實戰應用秘訣

### 1. 貫穿型長旋律對位插音（解鎖頻繁換和弦）
- **情境**：右手寫了一段 2~4 小節流暢的固定旋律（如 `C-D-E-F-G-A-B-C`），左手每兩拍換一次和弦（`C ➔ Am ➔ F ➔ G`）。
- **作法**：
  1. 樂符**直接寫入真實音高**（絕對不要削成 CM7）。
  2. 將該軌放在 **`Phrase 1 (Ch 14)`** 或 **`Phrase 2 (Ch 15)`**。
  3. CASM 規則設定為：**`NTR = Root Fixed` 且 `NTT = Bypass`**。
  4. 琴端演奏時，左手伴奏和弦（Chord/Bass）正常變換，右手的副旋律穩如泰山、100% 依譜發聲！

### 2. 前奏 / 尾奏（Intro / Ending）的左手解鎖防呆神技
- **傳統痛點**：Intro 設為 `Root Transpose + Bypass` 時，雖然支援單鍵根音移調，但前奏播放的 8 小節內，左手必須僵在空中不敢按鍵，否則前奏立刻走音翻車。
- **終極解法（混搭 CASM 模式）**：
  - 伴奏軌（`Chord 1/2`、`Bass`）：設為 **`Root Transpose + Chord`**。
  - Solo 主奏軌（`Phrase 1/2`）：設為 **`Root Fixed + Bypass`**。
  - **演奏效果**：前奏播放時，樂手左手可以自然地跟著譜彈奏 `C ➔ Am ➔ F ➔ G` 伴奏，而前奏中的薩克斯風或吉他 Solo **完全不受左手干擾，100% 防呆絕不翻車**！
