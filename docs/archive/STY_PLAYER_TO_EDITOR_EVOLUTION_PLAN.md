# Yamaha STY 播放器升級「單軌聚焦編輯器」執行計畫

## 1. 緣起與架構革新決策

### 1.1 歷史痛點回顧
在前期開發的完整編輯器（`index.html`）中，當多個音軌同時繪製鋼琴捲軸、格線、音符並伴隨畫面即時滾動時，瀏覽器的主執行緒（Main Thread）承受了極高的 DOM / Canvas 繪圖重載，導致：
1. **計時器漂移（Timer Drift）**：播放越到後面拍子越不準。
2. **畫面與音訊卡頓**：滾動畫面往下走時，視覺與聲音出現明顯延遲。
3. **介面狹窄擠迫**：8 個音軌擠在同一個螢幕，每軌高度過低，難以用滑鼠點選與微調音符。

### 1.2 突破性成果
透過獨立開發的純 STY 播放器（[player.html](file:///d:/Vibe%20Coding/MIDI/player.html)），我們驗證了：
* 核心排程器 [`StyPlaybackEngine`](file:///d:/Vibe%20Coding/MIDI/src/player/sty-playback-engine.ts) 採用 Web Audio 高精度微秒時脈與超前預約佇列，在輕量化介面下 **8 軌同時播放完全零延遲、拍子精確無誤**。
* 成功實現 **Web MIDI 直連 PSR-SX920 原生發聲** 功能。

> [!IMPORTANT]
> **驗證環境特別標記**：
> 目前確認的「零延遲、拍子完全準確」是在**電腦端（瀏覽器軟體合成器環境）**完成驗證。待回家連結實體琴後，仍需在 **PSR-SX920 實體硬體端（Web MIDI 輸出模式）** 再次進行完整發聲、拍子準確度與全軌發聲數確認。

### 1.3 核心架構決策：單軌聚焦編輯（Focus Track Editing）
借鑑 Logic Pro、Cubase、FL Studio 等專業 DAW 的標準工作流：
* **音訊排程與介面重繪徹底解耦**：背景繼續由穩定精準的排程引擎處理 8 軌聲音。
* **畫面聚焦單一音軌**：每次最多僅開啟 1 個 Channel 進行精細編輯，將畫面渲染負載降到最低（降低 85% 以上），徹底杜絕效能雪崩。

## 3. 力度與控制參數調控規範（重要變更）

依使用者明確指示，**廢棄傳統下方佔空間且不易操作的「柱狀圖（Histogram/Velocity Lane）」**，改用直覺高效率的**「拉桿 ＋ 數值輸入框」雙向連動模組**：

1. **控制項型態**：
   * **水平拉桿（Range Slider）**：範圍 `1 ~ 127`，適合滑鼠快速滑動感受力度變化。
   * **數字直接輸入框（Number Input）**：範圍 `1 ~ 127`，字體清晰，支援鍵盤直接敲入精確數值（如 `100`、`115`、`127`）後按 Enter 立即生效。
   * **雙向即時連動**：拖動拉桿數字框即時跟動，鍵盤改數字拉桿即時跳轉。
2. **三種操作情境**：
   * **選取音符修改**：在鋼琴捲軸上點選某個音符，拉桿與輸入框自動讀取並顯示該音符目前的 Velocity；調整拉桿或輸入新數字即時更新該音符，並觸發一聲琴端/軟體音源試聽。
   * **批次修改**：框選多個音符時，輸入數值可一次性統一該群音符的力度。
   * **預設畫筆力度**：未選取任何音符時，拉桿與輸入框數值作為接下來「點擊新增音符」時的預設力度。
3. **優點**：
   * 釋放垂直高度，鋼琴捲軸可視範圍擴大 30% 以上。
   * 數值精確無誤差，避免在小柱狀圖上點不到目標數值的困擾。

## 4. 分階段實施路線圖（Roadmap）

### 階段一：卡牌選取聯動與播放列升級
* 為現有 [player.html](file:///d:/Vibe%20Coding/MIDI/player.html) 的 8 張 Channel 卡牌加入點擊事件與 `is-active-focus` 高亮樣式。
* 在混音台下方新增播放控制列，提供 **[▶ 播放全曲 (All)]** 與 **[🎧 僅播此軌 (Solo)]** 雙按鈕。
* 呼叫 [`StyPlaybackEngine`](file:///d:/Vibe%20Coding/MIDI/src/player/sty-playback-engine.ts) 的 Mute/Solo 邏輯，實現一鍵切換播放全曲或單軌。

### 階段二：單軌鋼琴捲軸介面掛載與播放連動
* 在播放列下方新增可收展的單軌編輯容器。
* 當使用者點選任一卡牌（例如 Ch 9 或 Ch 11），將該軌在當前段落（如 Main A）的音符資料取出並繪製於鋼琴捲軸。
* 播放時，僅於該單軌捲軸上更新平滑的播放游標線，確保 60 FPS 順暢度且零掉拍。

### 階段三：力度拉桿 ＋ 數字輸入框模組實裝
* 於鋼琴捲軸上方配置力度控制模組。
* 實作音符點選選取狀態（Active Note），實現拉桿與數字框的雙向數值綁定與試聽觸發。

### 階段四：單軌細部互動編輯（聚焦軌的完全控制）
* **第一步：音符互動編修（Note Interactive Editing）**【✅ 已完成】
  * **點擊空白處新增音符**：依當前量化單位（1/16、1/8、1/4、1/32 拍）自動吸附網格 Tick 與行音高，新增音符方塊並以預設力度寫入。
  * **選取音符與即時試聽**：點擊音符方塊選取高亮，同步將當前力度帶入上方拉桿與數字框，並透過 `previewNote` 即時發出該音色之試聽聲響。
  * **刪除音符**：支援鍵盤 `Delete` / `Backspace` 快捷鍵、音符方塊上點擊滑鼠右鍵直接刪除、或工具列 `[🗑️ 刪除音符]` 按鈕。
  * **拖曳移位（Pitch & Time）**：按住音符可任意水平移動拍子位置（依量化單位吸附）或縱向調整音高/鼓組音色，釋放時即時更新並試聽新音高。
  * **時值拉長/縮短（Resize Duration）**：音符方塊右側設有專屬白色拖曳把手，拖動時即時吸附量化步長調整發聲持續時值。
  * **量化選擇器**：工具列提供 1/16、1/8、1/4、1/32 拍解析度即時切換。
  * **即時雙向同步**：任何音符增刪、移位、時值或力度調整，立即透過 `setChannelEvents` 回寫至 `StyPlaybackEngine`，播放中無縫即時生效（零掉拍、零延遲），並即時更新聚焦軌橫幅之音符計數。
* **第二步：STY 伴奏檔案記憶體組裝與匯出下載**【✅ 已完成】
  * 實作 [`YamahaStyleModifier.replaceSectionChannelNotes`](file:///d:/Vibe%20Coding/MIDI/src/core/writer/style-modifier.ts)，支援將單軌編輯器或多段落修改後的音符完整回寫至 `parsed.tracks[0]`，自動維護 Delta-times 與 Track 0 標記。
  * 整合 [`YamahaWriter.validateAndWrite`](file:///d:/Vibe%20Coding/MIDI/src/core/writer/yamaha-writer.ts) 進行二進位組裝，並通過 100% 反向重新解析檢驗，byte-level 完整保留 CASM（轉調控制區塊）、OTS（右手單鍵設定音色）與自訂區塊。
  * 於 [player.html](file:///d:/Vibe%20Coding/MIDI/player.html) 頂部伴奏規格儀表板配置醒目的綠色 **[💾 匯出 STY 伴奏檔]** 按鈕，點擊後自動同步當前段落所有聲部與混音音量，並觸發瀏覽器下載（命名為 `{原檔名}_edited.sty`）。
  * 建立專屬單元測試 `tests/single-track-export.test.ts`，確認實體伴奏檔在編輯單軌後匯出並反向解析，CASM 與音軌結構 100% 完整通過！
